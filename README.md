# MSC-Projectz: The Vader Engine 🚀

**Version:** 1.07 (Jedi-Master-v2)
**Developer:** Jon Beatz
**Ecosystem:** WordPress / Next.js / Divi 4

## 🌌 Overview
MSC-Projectz is a high-performance, modular digital architecture designed for the **My Studio Channel** brand. It serves as the core infrastructure for building and managing a fleet of 10+ interconnected web applications, featuring advanced video portal capabilities and the proprietary **Vader Protocol** for development efficiency.

## 🛡️ The Vader Protocol
This repository strictly adheres to the Vader Protocol development standards:
- **Prefixing:** All custom functions and CSS classes utilize the `msc-` prefix to prevent framework conflicts.
- **Security:** Hardened PHP entry points (`defined('ABSPATH') || exit;`) and nonce-verified actions.
- **Aesthetic:** Optimized for "Studio Dark" (#121212) with high-contrast UI elements.
- **Thermal Management:** Developed on the "Vader" workstation (Ryzen 7600X / RTX 5060 Ti) with specialized performance profiles.

## 🛠️ Key Features
- **Modular Video Portal:** Integrated with Bunny.net and Presto Player for high-fidelity media delivery.
- **Bento Dashboard:** A React/Next.js-based administrative interface featuring a modern grid layout.
- **Build Safety:** Automated Next.js `<Suspense>` wrapping for all `useSearchParams()` hooks to ensure 100% build success during production deployment.
- **Workflow Automation:** Optimized for AI-assisted development using custom `.cursorrules` and GitHub-to-AI Studio synchronization.

## 🚀 Deployment & Tech Stack
- **Hosting:** Spaceship
- **CMS:** WordPress / Payload CMS
- **UI Frameworks:** Divi 4, Advanced Custom Fields (ACF), and DiviGear CPT modules.
- **SMTP:** FluentSMTP via Brevo.com.
